# Proprexis CRM — Frontend

## Installation

```bash
cd frontend
npm install
npm run dev
```

Ouvre http://localhost:3000

## Prérequis
FastAPI doit tourner sur le port 8000 :
```bash
# Dans le dossier cleaning-ai-platform
uvicorn main:app --reload
```

## Stack
- Next.js 14 (App Router)
- Tailwind CSS
- Recharts (graphiques)
- Lucide React (icônes)
